Razorpay Website Clone
 Project Overview
This project is a simple, responsive clone of the Razorpay landing page, built specifically for learning and practicing modern front-end development using utility-first CSS. The goal was to replicate the clean, professional, and responsive aesthetic of a leading financial technology website to sharpen design and implementation skills.

Tech Stack
HTML5: Used for the semantic structure and content of the page.

Tailwind CSS: Employed as the sole CSS framework for utility-first styling, ensuring a fast, responsive, and consistent design across all components.

Features
Fully Responsive Layout: Designed to adapt flawlessly across all devices—from mobile phones to large desktops—using Tailwind's responsive utility classes.

Modern Aesthetic: Implements a sleek, dark hero section and clean feature grids, inspired by Razorpay's distinctive blue and purple branding.

Clean and Organized Code: The entire application is contained within a single index.html file with minimal custom CSS, showcasing the efficiency of Tailwind.

Author
This project was created by Ambreesh Singh as a practical exercise to improve front-end design and responsive web layout techniques.
